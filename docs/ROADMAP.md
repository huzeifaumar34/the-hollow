# THE HOLLOW — Roadmap

## Current milestone: 0.1.0 — First playable prototype

- [x] Native Android project and landscape activity
- [x] Canvas-based 2D renderer (no paid engine or external assets)
- [x] Touch movement and jump controls
- [x] Platforms, pits, spikes, and basic collision
- [x] Collectible fragments
- [x] Pressure plate and gate
- [x] Pursuing shadow and restart/checkpoint loop
- [x] GitHub Actions debug APK workflow

## Milestone 0.2 — Feel and readability

- [ ] Tune player acceleration, jump arc, and collision tolerances
- [ ] Add pause/settings screens and remappable touch zones
- [ ] Add camera smoothing and better parallax layers
- [ ] Add haptics and accessibility options

## Milestone 0.3 — Art and sound

- [ ] Replace prototype silhouettes with original environment artwork
- [ ] Add animation states and environmental effects
- [ ] Compose original ambient sound and gameplay effects
- [ ] Add graphics/performance settings for low-end devices

## Milestone 0.4 — Level design

- [ ] Build a complete forest chapter
- [ ] Add crate/weight puzzles and moving machinery
- [ ] Add checkpoints and hidden memory fragments
- [ ] Add level transition and save data

## Milestone 0.5 — Narrative

- [ ] Establish the protagonist's story through visual clues
- [ ] Design the abandoned settlement chapter
- [ ] Design the factory chapter
- [ ] Design the underground chapter

## Milestone 1.0 — Release candidate

- [ ] Full playthrough and balancing
- [ ] Device testing on ARM and older Android hardware
- [ ] Crash/performance profiling
- [ ] Signed release APK and release notes

All art, sound, levels, and code will be original. The project may take broad atmospheric inspiration from monochrome puzzle-platformers, but will not reuse another game's characters, levels, assets, or audio.
